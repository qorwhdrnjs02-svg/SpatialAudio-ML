# SpatialAudio-ML: Deep Learning Based Spatial Audio Synthesizer

**SpatialAudio-ML**은 사용자가 가상 공간 내에서 악기의 위치를 변경함에 따라 달라지는 소리의 특성(거리 감쇠, 잔향 등)을 딥러닝으로 학습하고 예측하는 인터랙티브 오디오 프로젝트입니다.

## 🎯 프로젝트 목표
- **물리 기반 오디오 합성**: `pyroomacoustics`를 활용하여 좌표(x, y)에 따른 가상 음향 데이터셋 구축.
- **오디오 특징 추출**: 오디오 신호를 MFCC 및 Mel-Spectrogram으로 변환하여 딥러닝 모델에 적합한 데이터로 가공.
- **공간 음향 회귀 모델링**: 특정 좌표값과 원본 소리를 입력받아 변형된 소리를 예측/생성하는 모델 학습.
- **인터랙티브 웹 데모**: 학습된 모델을 ONNX/TensorFlow.js로 변환하여 GitHub Pages에서 실시간 UX 구현.

## 🛠 기술 스택
- **Language:** Python 3.14+
- **Audio Processing:** Librosa, PyRoomAcoustics, SoundFile
- **Deep Learning:** PyTorch
- **Environment:** Anaconda / Jupyter Notebook
- **Version Control:** Git / GitHubg

# 🎧 SpatialAudio-ML: 3D 공간 음향 위치 추정 프로젝트

인공지능(CNN)을 활용하여 실내 공간 내 소리 발생 지점(x, y, z)을 추정하는 오디오 딥러닝 프로젝트입니다.

---

## 📂 프로젝트 마일스톤 (Milestones)

### 1️⃣ 데이터 생성 (Data Generation)
* **환경 구축**: `pyroomacoustics` 라이브러리를 활용하여 가상 3D 공간 시뮬레이션 환경($5m \times 5m \times 5m$) 구현.
* **물리 시뮬레이션**: 무작위 좌표($x, y, z$)에 소리 소스를 배치하고, 중앙에 고정된 마이크($2.5, 2.5, 2.5$)로 도달하는 음향 신호 생성.
* **디지털 변환**: 원본 오디오를 딥러닝 모델이 학습 가능한 **MFCC(Mel-Frequency Cepstral Coefficients)** 행렬($1262 \times 13$)로 변환.

### 2️⃣ 데이터셋 구축 (Dataset Prep)
* **데이터 저장**: 1,000개의 시뮬레이션 샘플을 약 608MB 규모의 JSON 데이터셋으로 구축.
* **데이터 검수**: 시각화 스크립트를 통해 좌표 변화에 따른 MFCC 패턴(Heatmap)의 변이 확인 및 데이터 무결성 검증.

### 3️⃣ 모델 설계 (CNN Architecture)
* **구조**: `Keras/TensorFlow` 기반의 CNN(Convolutional Neural Network) 아키텍처 설계.
* **학습 방식**: 위치 좌표를 예측하는 **Regression(회귀)** 모델 구축.
* **평가 지표**: 실제 좌표와 예측 좌표 사이의 거리 오차를 미터(m) 단위로 측정하는 **MAE(Mean Absolute Error)** 채택.

### 4️⃣ 학습 및 진단 (Training & Diagnosis)
* **결과**: 현재 MAE 약 **1.2m** 수준에서 학습 정체 현상 발생.
* **문제점 파악**: 모델이 특정 패턴을 찾는 대신 전체 데이터의 중앙값으로 수렴하는 **평균 수렴(Mean Convergence)** 문제 확인.
* **원인 분석**: 3D 공간 전체를 커버하기에 데이터 양(1,000개)이 부족하여 모델이 공간 물리 법칙을 충분히 학습하지 못함.

# 🔊 Spatial Audio Location Estimation (CNN-based)

이 프로젝트는 실내 공간 내 음원의 위치(x, y)를 추정하는 딥러닝 모델을 구축하는 프로젝트입니다.

## 🚀 진행 상황 및 업데이트 (2026-02-19)

### 1. 환경 및 시뮬레이션 개선
- **공간 확장:** 5m x 5m 방에서 **10m x 10m** 대형 공간으로 확장하여 위치 변별력을 높였습니다.
- **마이크 배치:** 중앙 고정 방식에서 **구석(2.0, 2.0)**으로 이동 배치하여 소리의 거리 감쇄와 반사음 패턴이 극명하게 나타나도록 수정했습니다.
- **스테레오 도입:** 기존 모노(1채널) 마이크에서 **스테레오(2채널) 마이크**로 업그레이드하여 ITD(시간차)와 ILD(에너지차) 정보를 학습에 포함시켰습니다.

### 2. 주요 시행착오 및 해결 (Lessons Learned)
- **중앙 쏠림 현상 (Central Bias):** - 원인: 데이터의 변별력 부족 및 모노 마이크의 대칭성 문제로 모델이 평균값(중앙)만 예측함.
  - 해결: 스테레오 채널 도입 및 방 크기 확장으로 데이터 특징을 강화함.
- **데이터 규격(Inhomogeneous Shape) 오류:**
  - 원인: 시뮬레이션 환경 변화로 MFCC의 시간축 길이가 미세하게 달라져 `numpy array` 변환 실패.
  - 해결: `np.zeros`를 활용한 패딩(Padding) 및 트리밍(Trimming) 로직을 추가하여 입력을 `(1262, 13, 2)`로 강제 통일함.
- **학습 차원 불일치 (5D vs 4D):**
  - 원인: 데이터 전처리 과정에서 불필요한 차원이 추가되어 `Conv2D` 입력 에러 발생.
  - 해결: `np.squeeze()`를 통해 차원을 재조정하여 모델 빌드 성공.
- **GitHub 대용량 파일 푸시 오류:**
  - 원인: 1.8GB의 JSON 데이터 파일과 LFS 기록이 Git 히스토리에 남아 푸시 거부.
  - 해결: `.git` 초기화 및 `.gitignore` 설정을 통해 대용량 데이터 파일을 제외하고 코드 중심으로 형상 관리 최적화.

## 🛠️ 다음 단계 계획
1. **마이크 간격 확장 (Stereo Width):** 현재 약 20cm인 간격을 50cm~1m로 넓혀 방향 감각 극대화.
2. **데이터 물량 공세:** 현재 1,000개에서 **5,000개~10,000개**로 샘플 수를 대폭 늘려 정교한 위치 추정 도모.
3. **학습 최적화:** MAE/MSE 지표 모니터링을 통한 오차 거리 0.x미터 진입 목표.
